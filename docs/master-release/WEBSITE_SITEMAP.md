# 10. PUBLIC SAAS WEBSITE SITEMAP & STRUCTURE

## 1. Information Architecture
The public SaaS website presents NexusOMS V5 with the visual refinement of modern enterprise software (inspired by Ecomflow).

```
https://nexusoms.vn/
├── / (Landing Page: Enterprise Hero, Core Pillars, Live Sandbox Preview, FAQ)
├── /solutions (Industry Solutions: D2C Brands, Retail Chains, B2B Wholesalers, 3PL Hubs)
├── /pricing (Transparent Plans: Starter, Growth, Enterprise Custom)
├── /about (Mission, Astrological Foundation: Tuyen Trung Thuy, Technical Stack)
├── /contact (1-on-1 Architecture Consultation, Enterprise Demo Scheduling)
├── /demo (Standalone Interactive In-Memory Sandbox with Zero DB Mutation)
├── /features/
│   ├── orders (OMS: Multichannel sync, deduplication, order routing)
│   ├── inventory (WMS: 5-state stock, FEFO batches, atomic lock)
│   ├── fulfillment (Wave picking, SLA countdown, scan-to-pack)
│   └── finance (Double-entry balanced ledger, fee reconciliation, circuit breaker)
├── /login (User Authentication)
├── /register (Organization Registration & Workspace Creation)
├── /forgot-password (Password Recovery Link Request)
├── /reset-password (Secure Password Reset Token Submission)
├── /verify-email (Email Confirmation Waiting Screen)
├── /accept-invite (Workspace Team Membership Acceptance)
├── /onboarding (6-Step Interactive Business Configuration Wizard)
└── /app/* (Authenticated OMS/WMS Workspace)
```
